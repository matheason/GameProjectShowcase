## 📖 Project Overview & Setting

**Title**: [Project Codename]
**Genre**: Action-Adventure / Puzzle-Platformer (Unity & C#)

> **Synopsis**: Set in a world divided into distinct material classes (Rock, Mud, Gel), players control a suppressed Gel recruit uncovering the truth behind ancient seismic Rifts and a corrupted council. 

### Key Design Pillars:
- **Material-Based Mechanics**: Physics and interaction logic built around the unique properties of Gel, Mud, and Rock.
- **Dynamic Wave Sensing**: C# system simulating seismic wave detection for puzzle-solving and environmental traversal.
